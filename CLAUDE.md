# Сайт услуг SEO-продвижения (Astro)

Это главный файл с требованиями к сайту. Claude читает его автоматически в начале каждой работы
с этим репозиторием. Новое требование = новая строка в разделе «Требования».

## О проекте

- Владелец: Алексей Пажитнов (info@on-projects.ru, Telegram @FunkyXL). Общаемся на русском.
- Сайт услуг по SEO-продвижению и портфолио. Контент взят со старого сайта https://on-projects.ru
- Фреймворк: Astro. Сайт статический, своего сервера нет.
- Владелец работает на Windows: команды запускаются как `npm.cmd run dev`, `npm.cmd run build`.

## Требования

1. **Три языка.** Основной домен будет `mysite.es`:
   - `mysite.es/` — испанский (язык по умолчанию, без префикса в адресе);
   - `mysite.es/ru/` — русский;
   - `mysite.es/en/` — английский.
   Каждая страница существует на всех трёх языках. На каждой странице есть переключатель языка,
   который ведёт на ту же страницу на другом языке.
2. **Страницы:** главная, «Услуги» (тарифы), «Портфолио», «Контакты».
3. **Форма «Заказать аудит сайта»** на странице контактов: адрес сайта, телефон, выбор мессенджера
   (Telegram, WhatsApp, MAX), кнопка «Отправить на аудит». Заявки отправляются через Web3Forms;
   ключ хранится в `formAccessKey` в `src/data/site.ts` (пустой ключ = открывается письмо на почту).
4. **Цены в евро (€) на всех языках.** Рубли на сайте не используются.

## Как устроен код

- `src/pages/` — адреса сайта. `src/pages/*.astro` = испанский, `src/pages/ru/` и `src/pages/en/` =
  русский и английский. Эти файлы короткие: они только подключают страницу из `src/views/`.
- `src/views/` — сами страницы. Одна страница на все языки; язык берётся из `Astro.currentLocale`.
- `src/i18n/ui.ts` — все надписи интерфейса (меню, кнопки, заголовки) на трёх языках.
- `src/data/` — контент на трёх языках: `site.ts` (контакты, слоган), `services.ts` (тарифы),
  `portfolio.ts` (кейсы).
- Добавляя новую страницу: создать её в `src/views/`, затем три файла в `src/pages/`, `src/pages/ru/`,
  `src/pages/en/`, и пункт меню в `src/components/Header.astro`.
- Проверка: `npm run build` должен проходить без ошибок.
