# Сайт услуг SEO-продвижения (Astro)

Это главный файл с требованиями к сайту. Claude читает его автоматически в начале каждой работы
с этим репозиторием. Новое требование = новая строка в разделе «Требования».

## О проекте

- Владелец: Алексей Пажитнов (info@on-projects.ru, Telegram @FunkyXL). Общаемся на русском.
- Сайт услуг по SEO-продвижению и портфолио. Контент взят со старого сайта https://on-projects.ru
- Фреймворк: Astro. Сайт статический, своего сервера нет.
- Владелец работает на Windows: команды запускаются как `npm.cmd run dev`, `npm.cmd run build`.

## Требования

1. **Три языка.** Основной домен будет `mysite.es`:
   - `mysite.es/` — испанский (язык по умолчанию, без префикса в адресе);
   - `mysite.es/ru/` — русский;
   - `mysite.es/en/` — английский.
   Каждая страница существует на всех трёх языках. На каждой странице есть переключатель языка,
   который ведёт на ту же страницу на другом языке.
2. **Страницы:** главная, «Услуги» (тарифы), «Портфолио», «Контакты», «Аудит сайта» (`/audit`).
   В шапке есть синяя кнопка «Аудит сайта 99 €», ведёт на `/audit`. Тексты аудита — `src/data/audit.ts`
   (написаны своими словами по мотивам webbuilderagency.com/site-auditing, не копия).
3. **Форма «Заказать аудит сайта»** на странице контактов: адрес сайта, телефон, выбор мессенджера
   (Telegram, WhatsApp, MAX), кнопка «Отправить на аудит». Заявки отправляются через Web3Forms;
   ключ хранится в `formAccessKey` в `src/data/site.ts` (пустой ключ = открывается письмо на почту).
4. **Цены в евро (€) на всех языках.** Рубли на сайте не используются.
5. **Title и Description задаются вручную** для каждой страницы на каждом языке в `src/data/seo.ts`.
   Ничего автоматически к ним не добавляется. Новая страница = новый блок в этом файле на трёх языках.
6. **Светлая и тёмная тема.** По умолчанию светлая; посетитель переключает её кнопкой ☀️/🌙 в шапке,
   выбор запоминается в браузере. Цвета обеих тем — в `src/layouts/Layout.astro`.
7. **Кинематографичный первый экран** (`src/components/Hero.astro`): сетка из тонких линий, крупный
   заголовок (без большого слова SEO2GO — убрали по просьбе владельца), синий блок с круглой кнопкой «Бесплатная консультация», подсказка «листайте».
8. **Картинка робота на первом экране** — статичное изображение `public/hero-robot.webp` (символ AI,
   фотореалистичный киборг в чёрно-синей броне, фон прозрачный). При наведении мышки робот плавно приближается.
   3D-робот на Three.js пробовали и убрали: выглядел примитивно.

## Дизайн: цвета и кнопки (обязательно для всех новых элементов)

Все цвета взяты из логотипа seo2go. Переменные заданы в `src/layouts/Layout.astro`; новых цветов не добавлять.

| Переменная | Цвет | Где используется |
|---|---|---|
| `--brand-blue` | `#0a73eb` | заливка всех кнопок, бейджей («ТОП»), номеров шагов, активного языка, синих блоков |
| `--brand-blue-hover` | `#075fc4` | заливка при наведении |
| `--brand-navy` | `#0f2244` | тёмно-синий из логотипа; основной цвет текста в светлой теме |
| `--on-brand` | `#ffffff` | текст на синей заливке |
| `--accent` | `#0a73eb` (тёмная тема `#4c9dff`) | ссылки, рамки, цены, выделения текста |
| `--accent-soft` | `#e7f1fe` (тёмная тема `#12284a`) | мягкий фон бейджей и наведения |

Кнопки — только общие классы, свои стили кнопкам не писать:
- `.btn` — основная: синяя заливка, белый текст, скругление 12px, жирный шрифт;
- `.btn-outline` — второстепенная: прозрачная, синяя рамка и текст;
- `.btn-white` — на синем фоне: белая кнопка с синим текстом;
- `.btn-sm` — маленький размер (например, кнопка «Аудит сайта 99 €» в шапке).
Фиолетовый цвет больше не используется (был до 2026-11-02).

## Как устроен код

- `src/pages/` — адреса сайта. `src/pages/*.astro` = испанский, `src/pages/ru/` и `src/pages/en/` =
  русский и английский. Эти файлы короткие: они только подключают страницу из `src/views/`.
- `src/views/` — сами страницы. Одна страница на все языки; язык берётся из `Astro.currentLocale`.
- `src/data/seo.ts` — Title и Description всех страниц на трёх языках.
- `src/i18n/ui.ts` — все надписи интерфейса (меню, кнопки, заголовки) на трёх языках.
- `src/data/` — контент на трёх языках: `site.ts` (контакты, слоган), `services.ts` (тарифы),
  `portfolio.ts` (кейсы).
- Добавляя новую страницу: создать её в `src/views/`, затем три файла в `src/pages/`, `src/pages/ru/`,
  `src/pages/en/`, и пункт меню в `src/components/Header.astro`.
- Проверка: `npm run build` должен проходить без ошибок.
