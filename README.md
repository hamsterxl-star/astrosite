# Сайт услуг по продвижению сайтов

Сделан на [Astro](https://astro.build).

## Как запустить у себя на компьютере

1. Установите Node.js (версия 22 или новее): https://nodejs.org
2. Откройте терминал в этой папке и выполните:

```
npm install
npm run dev
```

3. Откройте в браузере http://localhost:4321

## Где что менять

Сайт на трёх языках: `/` испанский, `/ru/` русский, `/en/` английский.
Все требования и устройство проекта описаны в [CLAUDE.md](CLAUDE.md).

- `src/data/site.ts` — контакты, имя и слоган на трёх языках.
- `src/data/services.ts` — тарифы, цены и дополнительные проверки.
- `src/data/portfolio.ts` — проекты в портфолио.
- `src/i18n/ui.ts` — надписи меню, кнопок и заголовков на трёх языках.
- `src/views/` — сами страницы (одна на все языки).
- `src/pages/` — адреса страниц: испанские в корне, русские в `ru/`, английские в `en/`.
- `src/components/` — повторяющиеся блоки: шапка, подвал, карточки, форма.
- `src/layouts/Layout.astro` — общий каркас и цвета сайта.
- `public/` — картинки и другие файлы, которые отдаются как есть.
